A fun, interactive, and educational implementation of the classic **Pac-Man** game built using **React**. This project serves as a technical showcase to demonstrate how to effectively manage complex game states using **React Hooks** and the **Context API**.

---

## 🚀 Game Overview
Pac-Man React brings the arcade nostalgia to the browser. The project focuses on clean architecture, using React's powerful state management to handle player movement, collision detection, and dynamic difficulty scaling.

* **Difficulty Levels:** Choose between Easy, Medium, and Advanced.
* **Responsive State:** Tracks your score and time elapsed in real-time.
* **Educational Codebase:** Designed to show how to structure game logic with React components and Context.

## 💻 Getting Started

Follow these steps to get the game running on your local machine.

### Prerequisites
* [Node.js](https://nodejs.org/) (v16+)
* `npm` or `yarn`

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/SheharBano404/React-Game-Project.git
   cd pacman-react

2. **Install Dependencies**
   ```bash
   npm install

3. **Start the Development Server**
   ```bash
   npm start

---

*Your game will be live at: http://localhost:3000* 🚀

## 🎮 How to Play

* **Select Difficulty:** Choose your preferred level (Easy / Medium / Advanced) from the dropdown menu on the start screen.

* **Start Game:** Click the "Play!" button to begin the game.

* **Control:** Navigate your Pac-Man, consume all the dots (pellets), and avoid the ghosts.

* **Game Over:** If a ghost catches you, the game will pause and display your score. Click "Try Again" to challenge yourself once more!
